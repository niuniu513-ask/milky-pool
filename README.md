# 奶蛙台球 · 奶娃俱乐部

在线游玩：[GitHub Pages](https://niuniu513-ask.github.io/milky-pool/)。也可将整个项目下载后，用浏览器打开 `index.html` 离线游玩。保留原有闯关、无尽关卡、加塞与三档 AI 模式，新增奶娃陪练与收集册。

## 本次完善

- 奶油黄／蛋黄／蜂蜜配色；母球换成奶娃崽立绘。
- 手机统一横屏：竖持时整页旋转，横持时正常显示；旋转后点击、拉杆、加塞坐标同步转换。提供全屏横屏按钮，浏览器不支持锁定方向时仍保留横屏布局。
- 手机侧边操作区：力度滑块、独立出杆、左右微调、自由摆母球、玩法与全屏；最小屏幕采用紧凑布局。
- 四种练习：直线入袋、切球、借库、自由清台；不限杆数，可重新摆母球，不影响闯关存档或收藏。
- 九形态收集册、七项荣誉、三张球桌；累计接回 12／30 只奶娃解锁荷塘／草莓主题。
- 瞄准线可关闭，新增一次碰库路线与库边刻度；音效可关闭，切至后台自动暂停。
- AI 对战改为完整十五球，修复分组、黑 8、自由球、难度 0、回合重复结算和弹窗问题；AI 会检查目标球至球袋及母球至接触点的遮挡。
- 修复拉杆角度累计漂移、暂停后 AI 定时器遗留、已入袋球参与碰撞、清台下一关存档，以及重打本关得分累积。

## 操作

鼠标移动瞄准；手机轻点目标方向。按住台面并向后拉，松手出杆；也可调节奶力后点「出杆」。方向键左右微调，上下调力度，空格出杆，Esc 暂停。加塞盘上跟、下缩、左右塞，点中心复位。手机端的音效和辅助开关位于「玩法」中。

## 存档

原 `milkyPool.best`、`bestLevel`、`board`、`progress`、`vs` 存档键继续使用，新增 `milkyPool.club` 保存收藏、主题和设置。存档属于当前浏览器与访问来源；直接打开文件与 HTTP 预览拥有不同存储空间。

原文件备份在 `backups/index.original.html`。

## 本地预览与验证

在游戏目录运行：

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

浏览器访问 `http://127.0.0.1:8765/`。安装好 agent-browser 后，另一终端运行：

```powershell
./tests/run.ps1
```

测试覆盖五种尺寸（1280×800、844×390、390×844、568×320、320×568），每种 67 项规则、物理、存档、输入及素材回归，共 335 项；结果写入 `tests/results.json`。浏览器尺寸模拟已验证，未连接实体 iOS／Android 设备。参考资料见 `SOURCES.md`。

## 奶娃动作素材

新增从公开奶蛙桌宠仓库取得的六种动作：待机、招手、大笑、低头、害羞、思考。大厅使用招手动作，陪练在自由球和对手回合切换对应表情。九种球体图片内嵌；陪练与大厅动作图片从 `assets/naiwa/` 加载，请与 HTML 一起保留。减少动态效果设置下使用静态替代。具体来源与第三方素材授权边界见 `SOURCES.md`。

## 自由球与禁打标识更新

- 修复白球进袋时动画读取空贴图、导致绘制循环中断的问题；白球落袋动画使用奶娃贴图，并保护图片尚未加载或不存在的情况。
- 闯关、陪练的白球落袋统一转为自由球，不额外罚杆；对战中犯规给对手自由球。摆放时显示可移动的白球预览，拒绝袋口与球体重叠位置，摆好后恢复出杆。黑八伴随白球落袋仍按对战规则判负。
- 对方球采用红色圆环与“禁打”标签，未能合法击打的黑八同样标注。己方可打球显示绿色圆环；清完己方球后自动解除黑八标记。瞄准禁打球时提示首触犯规，关闭辅助线也保留标签。
- 页面及画布文案全部中文化，新增奶黄包应援贴纸、奶家人小头像、奶油圆角按钮与陪练对话气泡。

新增回归包含白球落袋后的连续动画帧、合法／非法自由球摆放、双方落袋换手、旋转屏幕预览和点击、暂停恢复、禁打规则反转、九张贴图解码、页面及画布英文检查。
